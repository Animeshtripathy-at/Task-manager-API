# Task Manager REST API

A RESTful task management API built with Python and FastAPI.

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- SQLite
- APScheduler

## Features

- User, project and task management
- CRUD operations
- Request validation
- Error handling
- Pagination
- Background task scheduling
- Swagger API testing

## Run

```bash
pip install -r requirements.txt
uvicorn main:app --reload
